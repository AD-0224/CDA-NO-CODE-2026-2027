### Main Projects

#### 1. Shōnen Chronicle 90–2026 (`site1.html`)

An interactive retro manga magazine and character encyclopedia dedicated to iconic Shōnen heroes.

* **Features:**
  * Built-in 8-bit retro soundtrack synthesizer using the **Web Audio API**
  * Era filtering (1990s to 2020s) and real-time search bar
  * Full CRUD functionality (create, edit, delete, and like character articles) persisted via `localStorage`
  * Manga-inspired visual effects (halftone patterns, speed rays, click sound-effect popups)
* **Tech & Concepts:** HTML5, Tailwind CSS, Vanilla JS, Web Audio API, LocalStorage

#### 2. Chez Minou-Délice (`site2.html`)

A vintage, kitsch-styled cat tearoom website featuring a real-time interactive 3D mascot.

* **Features:**
  * Interactive 3D chocolate cat ("Noisette") rendered with **Three.js** (drag to rotate, click to jump, blinking eyes, animated tail)
  * Filterable pastry & drink menu with live tray/cart calculation and table booking form
  * Playful micro-interactions (paw-print cursor trail, virtual petting counter, "cat invasion" particle rain)
* **Tech & Concepts:** Three.js (WebGL), Tailwind CSS, Vanilla JS, CSS Keyframe Animations

#### 3. BONBON.BOLD (`site3.html`)

A Neo-Brutalist pastel e-commerce storefront for an artisan candy brand.

* **Features:**
  * Interactive wavy typography, jelly-wobble physics, and candy confetti bursts on click
  * Product catalog with category filtering and slide-out shopping cart drawer
  * Dynamic free-shipping progress bar and custom "Mix & Match" candy bag builder
* **Tech & Concepts:** Tailwind CSS, Neo-Brutalist UI, E-Commerce Cart State Management, IntersectionObserver

#### 4. PLAYPULSE 2026 (`site4.html`)

A dark-mode gaming release tracker and personal wishlist hub for upcoming 2026 titles.

* **Features:**
  * Interactive vertical 3D-feel card carousel controlled via mouse wheel, drag, touch, or keyboard arrows
  * Dynamic **Three.js** wireframe background that smoothly shifts color to match the active game
  * Floating Dynamic Island navigation bar, platform filters (PS5, PC, Switch 2, Xbox), and custom game submission form
* **Tech & Concepts:** GSAP, Three.js, Glassmorphism UI, Custom SVG Artwork Generator, LocalStorage

#### 5. Aurelia (`site5.html`)

An educational health and medication reference platform designed for clarity and patient safety.

* **Features:**
  * Interactive **3D molecular viewer** (Three.js) with bond/volume toggle and drag rotation
  * Hybrid search engine combining a local clinical database with the external **NIH RxNorm REST API**
  * Interactive 24-hour pharmacokinetic SVG curve (single vs. spaced doses) and weight-based dosage calculator
  * Cross-interaction prescription analyzer with JSON/CSV export and **Web Speech API** audio reading
* **Tech & Concepts:** Three.js, GSAP + ScrollTrigger, Lenis Smooth Scroll, REST API (`fetch`), Web Speech API

### Projets principaux

#### 1. Shōnen Chronicle 90–2026 (`site1.html`)

Un magazine web rétro et une encyclopédie interactive dédiée aux héros cultes du manga Shōnen.

* **Fonctionnalités :**
  * Synthétiseur musical rétro 8-bit intégré via la **Web Audio API**
  * Filtrage par décennie (1990 à 2020) et barre de recherche instantanée
  * Gestion complète des fiches (création, modification, suppression et likes) sauvegardée dans le `localStorage`
  * Effets visuels inspirés du manga papier (trames halftone, rayons de vitesse, onomatopées au clic)
* **Technologies & Notions :** HTML5, Tailwind CSS, JavaScript Vanilla, Web Audio API, LocalStorage

#### 2. Chez Minou-Délice (`site2.html`)

Un site vitrine et de commande pour un salon de thé vintage mettant en scène une mascotte 3D interactive.

* **Fonctionnalités :**
  * Chaton 3D interactif (« Noisette ») modélisé avec **Three.js** (rotation à la souris, saut au clic, clignement des yeux, queue articulée)
  * Carte filtrable de boissons et pâtisseries avec calcul dynamique du plateau et formulaire de réservation
  * Micro-interactions ludiques (traces de pattes suivant le curseur, compteur de ronrons, pluie de chatons)
* **Technologies & Notions :** Three.js (WebGL), Tailwind CSS, JavaScript Vanilla, Animations CSS

#### 3. BONBON.BOLD (`site3.html`)

Une boutique e-commerce au style néo-brutaliste pastel dédiée à une confiserie artisanale.

* **Fonctionnalités :**
  * Typographie interactive au survol, animations effet gélatine et explosions de confettis sucrés
  * Catalogue filtrable par saveur et tiroir panier latéral avec jauge de livraison offerte
  * Atelier interactif « Compose ton Sachet » permettant de sélectionner le format et de mixer ses parfums
* **Technologies & Notions :** Tailwind CSS, UI Néo-Brutaliste, Gestion d'état panier, IntersectionObserver

#### 4. PLAYPULSE 2026 (`site4.html`)

Un calendrier interactif et gestionnaire de Wishlist pour les sorties jeux vidéo attendues en 2026.

* **Fonctionnalités :**
  * Carrousel vertical fluide pilotable à la molette, au glissement tactile ou au clavier
  * Arrière-plan 3D **Three.js** réactif qui adapte sa couleur à celle du jeu sélectionné
  * Barre de navigation Dynamic Island, filtres par plateforme (PS5, PC, Switch 2, Xbox) et formulaire d'ajout de jeu
* **Technologies & Notions :** GSAP, Three.js, Glassmorphisme, Génération d'illustrations SVG, LocalStorage

#### 5. Aurelia (`site5.html`)

Une plateforme pédagogique d'information sur les médicaments et le suivi d'ordonnance.

* **Fonctionnalités :**
  * Visualiseur **3D moléculaire** interactif (Three.js) avec bascule liaisons/volume
  * Moteur de recherche hybride combinant une base locale et l'**API REST internationale RxNorm (NIH)**
  * Courbe pharmacocinétique SVG sur 24h, calculateur de dose selon le poids et lecture audio (**Web Speech API**)
  * Analyseur d'ordonnance détectant les doublons et interactions croisées avec export JSON/CSV
* **Technologies & Notions :** Three.js, GSAP + ScrollTrigger, Lenis Smooth Scroll, API REST (`fetch`), Web Speech API
